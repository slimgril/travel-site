## 目的

將網站內容由「旅遊景點介紹」正式轉型為「旅行札記」。

讀者應感受到的是旅人在路上的親身經歷，而非翻閱旅遊手冊或百科全書。

Agent 角色：以**資深旅遊作家**改寫景點資訊成一段旅遊札記。

---

## 描述區寫作規則（v1.2 · HARD · Owner 定稿）

> 主站卡片寫成**一小段散文**，不顯示 emoji／區塊標題。

1. **身在現場切入** — 從一個具體的感官細節開始（光線、聲音、第一眼畫面）。**禁止**以「這是 XXX」開頭。
2. **資訊嵌入敘事** — 歷史／年代／特色像順口帶出，**不要**條列式介紹。
3. **禁止導覽詞** — 禁用：「值得一遊」「不容錯過」「是 XX 的代表」及同類推銷句。
4. **禁止流水帳** — 禁用：「我們去了…然後看到…接著…」的時間順序堆疊。
5. **結尾留感受** — 一句個人感受或反思，帶畫面感或幽默感；**不要**下總結式結論。
6. **篇幅** — 全文 **4–6 句**，精簡有畫面；**不要**堆砌形容詞。

### 內部節奏（承接 v1.1，寫法服從上方 6 條）

當下感官 → 知識順口帶出 → 當下行動／雜記 → 感受收尾。  
比例仍約：知識 **20–30%**，現場與感受 **70%**。

### 參考範例（定稿 · 聖靈教堂古鐘）

> 抬頭的瞬間，金色羅馬數字先攫住視線——十七世紀的日輪鐘鑲在白牆紅瓦之間，藍白放射紋像被時間反覆擦亮過。導遊說這是老城裡「會講故事的鐘」，我半信半疑，直到晨光斜斜切過鐘面，金屬的光澤忽然活了起來。按下快門的那一刻突然明白：在塔林，連時間都捨得慢下來讓人看清楚。

## 其他寫作原則

1. **第一人稱旅行者視角** — 親眼所見、親身體驗、當下感受為主；可自然省略主詞。
2. **照片融入情境** — 斌哥入鏡時自然融入當下，不描述「這是一張合影」。
3. **一圖一故事** — 每張照片有自己的故事，不重複同一段景點介紹。
4. **一圖不拆兩卡（HARD）** — 同景近重複圖禁止拆兩卡；兩層意思併同一卡。
5. **保留結構** — 維持既有 Markdown 區塊，不更動 CSS 或 build 模板。
6. **餐食卡** — 可少帶知識，仍須現場感官＋感受收尾；同樣 4–6 句、禁導覽／流水帳。

---

## 避免（❌）

| 類型 | 範例 |
|------|------|
| 「這是 XXX」開頭 | 「這是十七世紀的日輪鐘」 |
| 導覽詞 | 「值得一遊」「不容錯過」「是 XX 的代表」 |
| 流水帳 | 「我們去了 A，然後看到 B，接著……」 |
| 總結式結尾 | 「為今天留下美好的回憶」「不虛此行」 |
| Wikipedia／條列史實 | 「建於 1660 年，為資助……」 |
| 設計論文 | 長篇「選址邏輯／設計意圖」 |
| 堆砌形容詞 | 「壯麗、震撼、令人驚嘆的……」連發 |
| 同圖拆兩卡 | 憲法牆＋「我是貓王」拆兩卡 |

---

## 應使用（✓）

- 從感官細節進場：抬頭、光線、聲音、踩到、氣味……
- 知識用「聽說／導遊說／原來……」等順口帶過
- 結尾用畫面或幽默的個人頓悟，而非評分式總結
