# 斌哥照片播放器（自行維護）

## 怎麼用

1. 雙擊 **`開始播放.command`**（首次若被擋：右鍵 → 打開）
2. 瀏覽器會開啟播放器首頁
3. 點 **「匯入照片／管理主題」**
4. 輸入**主題名稱**（＝資料夾名稱）→ 建立主題
5. 選照片或拖進框 → **開始匯入**
6. 回首頁，點該主題即可播放

## 資料放哪

```
player/bingge/Library/
  山西漫遊/          ← 主題＝資料夾名
    photo1.jpg
  波羅的海/
    ...
```

- 旅行書網站的札記圖**不會**被改動
- 刪主題只刪 `Library/` 裡該資料夾

## 說明

- 維護需要本機小伺服器（雙擊 command 即可），因為雲端靜態站無法自己收上傳
- 看照片、匯入都在 `http://127.0.0.1:8765/`
