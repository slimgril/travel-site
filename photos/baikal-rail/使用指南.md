**A:** 取决于：

## 🔧 故障排查

### 问题 1: 提示 "gdown command not found"

**原因:** gdown 未安装或未在 PATH 中

**解决:**
```bash
pip3 install gdown
# 或重新安装
pip3 install -U gdown
```

### 问题 2: 下载卡住不动

**原因:** 网络问题或 Google Drive 限流

**解决:**
1. 按 `Ctrl + C` 中断
2. 等待几分钟后重试
3. 或使用浏览器手动下载

### 问题 3: 提示 "Permission denied"

**原因:** 文件权限问题

**解决:**
```bash
# 给脚本添加执行权限
chmod +x sync_photos.py

# 检查目标目录权限
ls -la "/Users/mac/Documents/Projects/斌哥旅遊書/photos/"
```

### 问题 4: 大文件下载提示病毒扫描警告

**原因:** Google Drive 对大文件的安全检查

**解决:**
编辑 `sync_photos.py`，在 gdown 命令中添加 `--fuzzy` 参数：

```python
cmd = [
    "gdown",
    "--folder",
    GOOGLE_DRIVE_URL,
    "-O", str(TEMP_DOWNLOAD_DIR),
    "--remaining-ok",
    "--fuzzy"  # ← 添加这一行
]
```

### 问题 5: 文件夹名称无法识别

**症状:** 脚本提示 "无法从 'XXX' 提取日期编号"

**原因:** 文件夹名称不符合识别规则

**解决:**
1. 查看 Google Drive 中的实际文件夹名称
2. 手动修改映射逻辑，或
3. 手动重命名 Google Drive 中的文件夹为 "Day 1", "Day 2" 等格式

### 问题 6: Python 版本问题

**症状:** 提示 Python 版本相关错误

**检查版本:**
```bash
python3 --version
```

**要求:** Python 3.6 或更高版本（当前：3.14.6 ✅）

## 🎯 高级用法

### 方法 1: 直接使用 gdown 命令行

如果只想快速下载查看，不需要自动映射：

```bash
# 下载到临时文件夹
gdown --folder https://drive.google.com/drive/folders/1VnHEb__UrT7-MMOrTKfh8OB6lBFzE6Ty -O temp

# 查看内容
ls temp/

# 手动移动文件
mv temp/Day1/* day01/
mv temp/Day2/* day02/
```

### 方法 2: 增量同步（仅新文件）

目前脚本是全量覆盖。如需增量同步，使用 `rsync`:

```bash
# 先下载到 temp/
gdown --folder URL -O temp

# 增量同步（只复制新文件）
rsync -av --ignore-existing temp/Day1/ day01/
rsync -av --ignore-existing temp/Day2/ day02/
```

### 方法 3: 查看但不下载

```bash
# 使用浏览器直接访问
open "https://drive.google.com/drive/folders/1VnHEb__UrT7-MMOrTKfh8OB6lBFzE6Ty"
```
