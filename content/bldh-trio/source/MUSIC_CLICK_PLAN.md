## 互動與視覺規格

| 項目 | 規格 |
|------|------|
| 觸發 | 點擊景點卡片照片角落的微圖標 |
| 圖標 | **不用**標準 ▶️；用精緻線條「音符／小喇叭」或極簡黑膠符號，不破壞雜誌／卡片版面 |
| 長度 | 15–30 秒精華 |
| 音色處理 | **淡入（fade-in）＋淡出（fade-out）** |
| 行為 | 同頁同時僅一首；再開另一首則停掉前一首 |
| 無障礙 | `aria-label` 标明「播放／暫停配樂」；尊重系統「減少動態」時可關閉自動相關效果 |
