# 斌哥照片播放器（自行維護 · 不含預置照片）

## Windows（PC）

1. 確認已安裝 **Python 3**（安裝時勾選 *Add python.exe to PATH*）
2. 雙擊 **`START.bat（或 開始播放.bat）`**
3. 瀏覽器會開啟播放器首頁
4. 點 **「匯入照片／管理主題」**
5. 輸入**主題名稱**（＝資料夾名稱）→ 建立主題
6. 選照片或拖進框 → **開始匯入**
7. 回首頁，點該主題即可播放

## Mac

1. 雙擊 **`開始播放.command`**（首次若被擋：右鍵 → 打開）
2. 其餘步驟同上

## 資料放哪

```
Library/
  山西漫遊/          ← 主題＝資料夾名（自行命名）
    photo1.jpg
  波羅的海/
    ...
```

- 本包**不含照片**；照片由使用者自行匯入
- 也可直接把照片資料夾放進 `Library/`（資料夾名＝主題名），再重整首頁
- 刪主題只刪 `Library/` 裡該資料夾

## 說明

- 需要本機小伺服器（雙擊 bat／command 即可）
- 看照片、匯入都在 `http://127.0.0.1:8765/`
- 結束：在黑色視窗按 `Ctrl+C`，或直接關閉視窗

Windows 黑窗應顯示 `BinggePlayer LAUNCHER_V3`（用來確認不是舊檔）。
