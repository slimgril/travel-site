# 浏览器下载 + 自动处理 - 完整指南

## 📋 完整流程（推荐方案）

### 步骤 1: 从浏览器下载

```bash
# 自动打开 Google Drive
open "https://drive.google.com/drive/folders/1VnHEb__UrT7-MMOrTKfh8OB6lBFzE6Ty"
```

**在浏览器中：**
1. 选择要下载的文件夹（如 `0803`, `0804` 等）
   - 可以按住 Command 键多选
   - 或右键点击整个文件夹
2. 点击右上角的 ⋮ (三个点) → "下载"
3. Google Drive 会打包成 zip 文件并开始下载
4. 下载完成后文件在 `~/Downloads/` 目录

### 步骤 2: 自动处理

下载完成后，运行处理脚本：

```bash
cd "/Users/mac/Documents/Projects/斌哥旅遊書/photos/baikal-rail"
python3 process_download.py
```

脚本会：
- ✅ 自动找到 Downloads 中最新的 zip 文件
- ✅ 解压文件
- ✅ 识别日期文件夹（0803, 0804...）
- ✅ 映射到 day01, day02...
- ✅ 覆盖前备份
- ✅ 自动清理临时文件

### 指定 zip 文件

如果有多个 zip 文件：

```bash
python3 process_download.py "西伯利亚大铁路 20 日.zip"
```

## 🎯 使用场景

### 场景 1: 下载所有日期

1. 在浏览器中选择整个 "西伯利亚大铁路 20 日" 文件夹
2. 下载（会打包成一个 zip）
3. 运行 `python3 process_download.py`
4. 所有日期自动映射到 day01-day20

### 场景 2: 下载特定几天

1. 在浏览器中按住 Command 键，选择 `0803`, `0804`, `0805`
2. 下载
3. 运行脚本，只映射这几天

### 场景 3: 更新某天的照片

1. 下载单个日期文件夹（如 `0804`）
2. 运行脚本
3. 选择覆盖 day02

## ⚡ 优势

- ✅ **稳定**: 浏览器下载比命令行更可靠
- ✅ **断点续传**: 浏览器内置支持
- ✅ **无需配置**: 不需要 API 密钥或授权
- ✅ **自动化**: 下载后一键处理
- ✅ **灵活**: 可选择下载全部或部分

## 🔧 故障排查

### 问题 1: 脚本找不到 zip 文件

**解决**:
```bash
# 查看 Downloads 目录
ls -lt ~/Downloads/*.zip | head -5

# 手动指定文件
python3 process_download.py "文件名.zip"
```

### 问题 2: 解压后找不到日期文件夹

**原因**: zip 文件结构可能有嵌套

**查看临时解压目录**:
```bash
ls -R "/Users/mac/Documents/Projects/斌哥旅遊書/photos/baikal-rail/_temp_extract/"
```

### 问题 3: 日期映射错误

**检查**: 确保文件夹名称是 `0803`, `0804` 等格式
